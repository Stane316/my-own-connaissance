# 1\. LE PROBLÈME CENTRAL DU DOMAINE

Une excellente compétence technique ne garantit pas qu’un produit sera :

- remarqué ;
- compris ;
- considéré comme crédible ;
- choisi ;
- acheté ;
- recommandé ;
- financé.

Il existe donc une chaîne différente de celle de la construction technique.

On peut la résumer ainsi :

**IDENTITÉ → POSITIONNEMENT → VISIBILITÉ → ATTENTION → COMPRÉHENSION → CONFIANCE → CONSIDÉRATION → CONVERSION → RELATION → RÉPUTATION → RECOMMANDATION**

Le branding agit principalement sur **qui tu es et comment tu es perçu**.

Le marketing agit principalement sur **comment tu atteins un marché et génères de la demande**.

La communication agit sur **comment tu transmets un message**.

La vente agit sur **comment tu transformes une opportunité en transaction**.

Le personal branding agit sur **la perception professionnelle associée à une personne**.

Le contenu agit comme un **véhicule de visibilité, de preuve, d’éducation, de confiance et parfois d’acquisition**.

Ces domaines se chevauchent, mais ils ne sont pas identiques.

# 3\. DISTINCTIONS FONDAMENTALES

## Brand ≠ Logo

Un logo est un élément visuel.

Une marque est un ensemble beaucoup plus large :

**perceptions + associations + expériences + réputation + identité + promesse**

## Branding ≠ Marketing

Le branding construit notamment :

**« Pourquoi cette marque est-elle identifiable et mémorable ? »**

Le marketing cherche notamment :

**« Comment atteindre et convaincre le marché ? »**

## Marketing ≠ Vente

Le marketing crée et capture de la demande.

La vente transforme une opportunité en relation commerciale.

## Communication ≠ Marketing

La communication concerne principalement la transmission du message.

Le marketing englobe aussi :

- marché ;
- produit ;
- prix ;
- distribution ;
- acquisition ;
- segmentation ;
- analyse ;
- conversion.

## Personal Branding ≠ Se faire connaître

Être connu n’est pas nécessairement être crédible.

Le véritable objectif peut être :

**Être connu pour quelque chose, par les bonnes personnes, avec une perception cohérente avec la valeur que l’on veut apporter.**

# NIVEAU B — COMPRENDRE LE MARCHÉ AVANT DE COMMUNIQUER

# 4\. LE MARCHÉ

## Qu’est-ce qu’un marché ?

Un marché est un ensemble d’acteurs autour d’un problème, d’un besoin ou d’une catégorie d’offre.

Il implique notamment :

- des clients ;
- des utilisateurs ;
- des concurrents ;
- des alternatives ;
- des fournisseurs ;
- des contraintes ;
- des habitudes ;
- des canaux ;
- une capacité de paiement.

### Pourquoi ce concept existe-t-il ?

Parce qu’une offre ne fonctionne jamais dans le vide.

Une solution peut être excellente techniquement et pourtant avoir :

- une cible trop petite ;
- un mauvais prix ;
- un mauvais canal ;
- un mauvais positionnement ;
- un problème insuffisamment important.

### Quand y penser ?

Avant de définir :

- une offre ;
- un contenu commercial ;
- une campagne ;
- un produit ;
- un positionnement.

# 5\. SEGMENTATION

Un marché n’est pas homogène.

On peut le segmenter selon :

- géographie ;
- secteur ;
- taille d’entreprise ;
- âge ;
- comportement ;
- pouvoir d’achat ;
- besoin ;
- maturité ;
- technologie utilisée ;
- fréquence du problème.

### Exemple

« Entreprises africaines » est une cible extrêmement large.

On peut obtenir :

PME de services au Bénin

puis :

PME de services disposant déjà d’une présence numérique mais générant peu de demandes en ligne.

La seconde formulation est beaucoup plus exploitable.

# 6\. ICP — IDEAL CUSTOMER PROFILE

L’ICP décrit **le type de client idéal pour une activité**, principalement utilisé en B2B.

Il peut inclure :

- secteur ;
- taille ;
- localisation ;
- budget ;
- problème ;
- maturité ;
- outils ;
- déclencheur d’achat ;
- capacité de décision ;
- urgence.

### À ne pas confondre

**ICP ≠ persona**

L’ICP décrit généralement **l’organisation idéale**.

Le persona décrit plutôt **une personne-type** au sein du contexte ciblé.

# 7\. PERSONA

Le persona est une représentation structurée d’un utilisateur ou client-type.

Il peut inclure :

- objectifs ;
- frustrations ;
- motivations ;
- habitudes ;
- contexte ;
- objections ;
- comportements.

### Attention

Un persona inventé sans recherche peut devenir une fiction.

Il doit donc être considéré comme :

**hypothèse utile**, pas vérité absolue.

# 8\. JOBS TO BE DONE

Le concept cherche à comprendre :

**Quel “travail” le client cherche-t-il réellement à accomplir ?**

Exemple :

Le client ne veut pas forcément :

« un site web ».

Il peut vouloir :

« paraître professionnel et recevoir davantage de demandes de clients ».

Le produit demandé et le résultat recherché peuvent donc être différents.

# 9\. PROBLÈME, BESOIN, DÉSIR ET DEMANDE

Ces notions ne sont pas identiques.

### Problème

Une situation insatisfaisante.

### Besoin

Ce qui est nécessaire pour résoudre ou améliorer la situation.

### Désir

La manière dont la personne souhaite satisfaire ce besoin.

### Demande

Un désir soutenu par une intention et une capacité d’achat.

# 10\. PAIN POINT

Un pain point est une difficulté significative vécue par la cible.

Il peut être :

- financier ;
- opérationnel ;
- temporel ;
- émotionnel ;
- technique ;
- social ;
- stratégique.

Plus un problème est :

- fréquent ;
- coûteux ;
- urgent ;
- douloureux ;

plus il peut devenir commercialement intéressant.

# NIVEAU C — POSITIONNEMENT ET DIFFÉRENCIATION

# 11\. POSITIONNEMENT

Le positionnement répond à :

**Quelle place voulons-nous occuper dans l’esprit d’une cible donnée par rapport aux alternatives ?**

Une structure utile :

Pour [cible](#cible), nous sommes \[catégorie\] qui permet \[résultat\], contrairement à \[alternative\], grâce à \[différenciation\].

# 12\. PROPOSITION DE VALEUR

La proposition de valeur explique :

- pour qui ;
- quel problème ;
- quel résultat ;
- comment ;
- pourquoi cette solution.

Une bonne proposition de valeur n’est pas simplement :

« Nous créons des solutions digitales innovantes. »

C’est trop générique.

Elle doit réduire l’ambiguïté.

# 13\. USP / UNIQUE SELLING PROPOSITION

L’USP correspond à une proposition de vente différenciante.

Attention :

Une différence n’est intéressante que si elle compte pour le client.

# 14\. DIFFÉRENCIATION

On peut se différencier par :

- prix ;
- qualité ;
- vitesse ;
- expertise ;
- spécialisation ;
- expérience ;
- distribution ;
- technologie ;
- service ;
- confiance ;
- communauté ;
- marque ;
- localisation ;
- modèle économique.

### Principe important

**« Différent » n’est pas automatiquement « meilleur ».**

La différence doit être pertinente pour la cible.

# 15\. CATÉGORIE

Une marque peut être positionnée dans une catégorie existante.

Exemples :

- agence digitale ;
- SaaS ;
- cabinet de conseil ;
- outil de gestion ;
- plateforme éducative ;
- studio créatif.

Une catégorie permet au marché de comprendre rapidement :

« Ce que c’est. »

Le positionnement précise :

« Pourquoi celui-ci plutôt qu’un autre. »

# 16\. BRAND PROMISE

La promesse de marque exprime la valeur que la marque cherche à délivrer de manière cohérente.

Elle doit être :

- crédible ;
- pertinente ;
- compréhensible ;
- démontrable.

# NIVEAU H — PERSONAL BRANDING

# 45\. QU’EST-CE QU’UN PERSONAL BRAND ?

Le personal branding est la construction intentionnelle de la perception professionnelle associée à une personne.

Ce n’est pas :

« Poster tous les jours. »

C’est :

**Construire une réputation identifiable autour d’une valeur, d’une compétence, d’une perspective ou d’un domaine.**

# 46\. LA FORMULE DU PERSONAL BRANDING

Une approximation utile :

**PERSONNE + EXPERTISE + POSITIONNEMENT + PREUVES + CONTENU + RELATIONS + COHÉRENCE + TEMPS = RÉPUTATION**

# 47\. POSITIONNEMENT PERSONNEL

Il faut pouvoir répondre :

Qui suis-je professionnellement ?

Pour qui suis-je utile ?

Sur quels problèmes suis-je compétent ?

Quelle perspective particulière ai-je ?

Pourquoi devrait-on me faire confiance ?

# 48\. PERSONAL BRANDING ≠ INFLUENCE

Un influenceur cherche principalement à construire une audience et une influence.

Un professionnel peut utiliser le personal branding pour :

- obtenir des clients ;
- trouver des collaborateurs ;
- obtenir des opportunités ;
- être recruté ;
- attirer des partenaires ;
- obtenir des invitations ;
- obtenir des financements ;
- construire une réputation.

L’audience n’est donc pas nécessairement l’objectif final.

# 49\. AUTORITÉ

L’autorité professionnelle peut provenir de :

- compétence ;
- résultats ;
- expérience ;
- pédagogie ;
- constance ;
- preuves ;
- reconnaissance externe ;
- réseau ;
- originalité intellectuelle.

### Attention

Parler avec assurance n’est pas une preuve d’expertise.

# 50\. CRÉDIBILITÉ

La crédibilité est une perception de fiabilité.

Elle est renforcée par :

- cohérence ;
- précision ;
- transparence ;
- preuves ;
- réalisations ;
- références ;
- comportement professionnel.

Elle est détruite par :

- mensonges ;
- exagérations ;
- contradictions ;
- fausses statistiques ;
- promesses impossibles ;
- plagiat ;
- incohérence.

# 51\. PORTFOLIO

Le portfolio n’est pas seulement une galerie.

Il doit répondre :

« Qu’est-ce que cette personne sait réellement faire ? »

Une étude de projet efficace montre :

- contraintes ;

# 55\. LE PARCOURS COMMERCIAL SOCIAL

Une logique saine peut être :

VISIBILITÉ → CRÉDIBILITÉ → CONVERSATION → QUALIFICATION → PROPOSITION → NÉGOCIATION → CONTRAT → LIVRAISON → TÉMOIGNAGE → RECOMMANDATION

# 56\. PROSPECTION

La prospection consiste à rechercher activement des opportunités.

Elle peut être :

- directe ;
- indirecte ;
- digitale ;
- téléphonique ;
- événementielle ;
- partenariale.

# 57\. QUALIFICATION

Avant de vendre, il faut savoir si le prospect correspond réellement à l’offre.

Questions :

- Quel est son problème ?
- Est-il réel ?
- Est-il urgent ?
- Qui décide ?
- Quel budget existe ?
- Quelle solution utilise-t-il actuellement ?
- Quel est le délai ?
- Quel résultat recherche-t-il ?

# 58\. DISCOVERY CALL

Une discovery call cherche à comprendre :

- contexte ;
- problème ;
- objectifs ;
- contraintes ;
- urgence ;
- budget ;
- processus de décision.

Elle ne devrait pas être uniquement une présentation de soi.

# 59\. OBJECTION

Une objection est une raison exprimée ou implicite qui bloque l’achat.

Exemples :

- prix ;
- confiance ;
- timing ;
- priorité ;
- risque ;
- comparaison ;
- besoin de validation.

Une objection n’est pas automatiquement un refus définitif.

# 60\. PROPOSITION COMMERCIALE

Une proposition peut contenir :

1.  contexte ;
2.  problème ;
3.  objectifs ;
4.  approche ;
5.  livrables ;
6.  calendrier ;
7.  responsabilités ;
8.  prix ;
9.  conditions ;
10. validité ;
11. modalités de paiement ;
12. prochaines étapes.

# 61\. DEVIS ≠ PROPOSITION COMMERCIALE ≠ CONTRAT

### Devis

Document principalement lié au prix et aux prestations.

### Proposition commerciale

Document de persuasion et de cadrage de l’offre.

### Contrat

Document juridiquement engageant définissant les obligations et conditions.

Ils peuvent être combinés selon les pratiques, mais leurs fonctions sont différentes.

# NIVEAU J — VENDRE UNE OFFRE

# 62\. OFFRE

Une offre n’est pas simplement :

« Je sais faire X. »

Elle doit préciser :

- pour qui ;
- problème ;
- résultat ;
- périmètre ;
- livrables ;
- délai ;
- prix ;
- conditions ;
- différenciation.

# 63\. PRODUCTISATION D’UN SERVICE

Transformer une prestation personnalisée en offre relativement standardisée.

Exemple :

Au lieu de :

« Je peux créer votre présence digitale. »

Créer :

« Pack présence digitale PME : landing page + optimisation mobile + formulaire de contact + analytics + livraison en X jours. »

Cela facilite :

- compréhension ;
- vente ;
- estimation ;
- répétition ;
- délégation.

# 64\. VALUE-BASED SELLING

On peut vendre en fonction de la valeur créée plutôt qu’en fonction du nombre d’heures.

Exemple :

Si une solution permet à une entreprise d’améliorer significativement son acquisition, le raisonnement commercial peut se concentrer sur :

valeur créée → coût → retour potentiel.

Attention : la valeur doit rester crédible et démontrable.

# 65\. PRICING PSYCHOLOGY

La perception du prix dépend notamment de :

- valeur perçue ;
- alternatives ;
- confiance ;
- urgence ;
- risque ;
- positionnement ;
- présentation.

Le prix n’est donc pas uniquement une opération mathématique.

# NIVEAU K — MARKETING AFRICAIN ET CONTEXTES LOCAUX

# 66\. NE PAS TRAITER « L’AFRIQUE » COMME UN SEUL MARCHÉ

L’Afrique est constituée de marchés extrêmement différents.

Différences possibles :

- pays ;
- langue ;
- pouvoir d’achat ;
- infrastructure ;
- habitudes ;
- réglementation ;
- moyens de paiement ;
- réseaux dominants ;
- confiance ;
- distribution ;
- culture commerciale.

Il faut donc penser :

**Afrique → région → pays → secteur → segment → cible.**

# 67\. LOCALISATION

Une stratégie peut nécessiter :

- adaptation linguistique ;
- adaptation culturelle ;
- adaptation du prix ;
- adaptation du paiement ;
- adaptation des canaux ;
- adaptation du message ;
- adaptation des preuves.

Traduire ≠ localiser.

# 68\. CONFIANCE DANS LES MARCHÉS ÉMERGENTS

Dans certains contextes commerciaux, la confiance peut être particulièrement importante.

Elle peut être construite par :

- recommandations ;
- références ;
- témoignages ;
- partenaires ;
- démonstrations ;
- transparence ;
- contrats ;
- professionnalisme ;
- suivi.

Il ne faut cependant pas transformer cette observation en règle universelle applicable à tous les marchés africains.

# NIVEAU L — NETWORKING, PARTENARIATS ET COLLABORATIONS

# 71\. NETWORKING

Le networking consiste à construire des relations professionnelles utiles et authentiques.

Il ne signifie pas :

« connaître le plus de personnes possible ».

Il signifie plutôt :

**être connecté aux bonnes personnes dans un réseau où la confiance peut se développer.**

# 72\. PARTENARIAT

Un partenariat crée une relation dans laquelle plusieurs parties cherchent un bénéfice commun.

Exemples :

- distribution ;
- co-marketing ;
- intégration ;
- apport d’affaires ;
- contenu ;
- événement ;
- technologie ;
- financement.

# 73\. PARTENAIRE ≠ CLIENT

Le client paie généralement pour obtenir une valeur.

Le partenaire collabore pour créer ou distribuer de la valeur.

Un acteur peut parfois être les deux.

# 74\. COLLABORATEUR

Un collaborateur peut contribuer :

- techniquement ;
- commercialement ;
- créativement ;
- stratégiquement ;
- financièrement ;
- institutionnellement.

# 75\. AMBASSADEUR

Une personne qui représente, recommande ou diffuse une marque, une organisation ou un projet.

# 76\. COMMUNAUTÉ

Une communauté n’est pas seulement une audience.

Audience :

personnes qui consomment ton contenu.

Communauté :

personnes qui entretiennent une relation plus active autour d’un intérêt, d’une identité ou d’un objectif commun.

# NIVEAU M — PITCH, FINANCEMENT ET PRÉSENTATION DE PROJET

# 77\. PITCH

Un pitch est une présentation courte destinée à provoquer :

- compréhension ;
- intérêt ;
- confiance ;
- action.

# 78\. PITCH ≠ PRÉSENTATION COMPLÈTE

Un pitch ne doit pas nécessairement tout expliquer.

Son objectif peut être :

obtenir la prochaine conversation.

# 79\. STRUCTURE D’UN PITCH

Structure générale :

1.  problème ;
2.  cible ;
3.  importance du problème ;
4.  solution ;
5.  différenciation ;
6.  marché ;
7.  modèle économique ;
8.  traction ;
9.  équipe ;
10. vision ;
11. demande.

# 80\. PITCH DECK

Présentation généralement structurée autour de :

- problème ;
- solution ;
- produit ;
- marché ;
- business model ;
- go-to-market ;
- concurrence ;
- avantage ;
- traction ;
- équipe ;
- projections ;
- financement recherché.

La structure exacte dépend du contexte.

# 81\. TRACTION

La traction correspond aux signes montrant qu’un projet progresse réellement.

Exemples :

- utilisateurs ;
- clients ;
- revenus ;
- croissance ;
- rétention ;
- partenaires ;
- pilotes ;
- contrats ;
- communauté ;
- engagement.

Une idée seule n’est généralement pas de la traction.

# 82\. INVESTISSEUR ≠ CLIENT

Un client demande :

« Cette solution résout-elle suffisamment mon problème pour que je paie ? »

Un investisseur peut demander :

« Cette entreprise peut-elle devenir suffisamment importante et rentable pour justifier mon investissement ? »

Les deux nécessitent donc des argumentaires différents.

# 83\. FINANCEMENT

Sources possibles :

- autofinancement ;
- revenus ;
- subventions ;
- concours ;
- grants ;
- incubateurs ;
- accélérateurs ;
- business angels ;
- venture capital ;
- dette ;
- partenariats institutionnels ;
- sponsoring.

Chaque source implique :

- critères ;
- risques ;
- attentes ;
- contreparties.

# 84\. IMPACT

Dans certains projets africains ou à vocation sociale, l’impact peut être central.

Il peut être mesuré par :

- personnes touchées ;
- emplois ;
- revenus générés ;
- temps économisé ;
- accès amélioré ;
- réduction de coûts ;
- amélioration d’un indicateur social.

Mais :

**impact ≠ slogan.**

Il faut pouvoir le mesurer.

# NIVEAU N — MÉTRIQUES MARKETING

# 85\. MÉTRIQUES DE VISIBILITÉ

Exemples :

- impressions ;
- portée ;
- vues ;
- croissance d’audience.

# 86\. MÉTRIQUES D’ENGAGEMENT

- likes ;
- commentaires ;
- partages ;
- sauvegardes ;
- réponses ;
- durée de visionnage.

Attention :

engagement ≠ valeur commerciale.

# 87\. MÉTRIQUES D’ACQUISITION

- visiteurs ;
- leads ;
- coût par lead ;
- taux de conversion ;
- source d’acquisition.

# 88\. CAC

**Customer Acquisition Cost**

Coût moyen nécessaire pour acquérir un client.

Formule simplifiée :

CAC = dépenses d’acquisition / nouveaux clients

Attention aux périodes et au périmètre des coûts.

# 89\. CONVERSION RATE

conversions / population exposée ou étape précédente

Il faut toujours préciser :

conversion de quoi vers quoi ?

# 90\. ROAS

**Return On Ad Spend**

revenus attribués à la publicité / dépenses publicitaires

Attention :

ROAS ≠ bénéfice.

# 91\. LTV

**Lifetime Value**

Valeur économique attendue d’un client pendant sa relation avec l’entreprise.

La formule dépend du modèle économique.

Il ne faut jamais appliquer une formule simplifiée sans vérifier ses hypothèses.

# 92\. RETENTION

Pourcentage de clients ou utilisateurs qui restent actifs après une période donnée.

# 93\. CHURN

Proportion de clients ou revenus perdus pendant une période.

Dans un abonnement, on distingue notamment :

- customer churn ;
- revenue churn.

# 94\. REVENUE ≠ PROFIT

Revenue :

argent généré par les ventes.

Profit :

ce qui reste après les coûts selon la définition comptable utilisée.

Une entreprise peut avoir beaucoup de revenus et peu ou pas de profit.

# NIVEAU O — STRATÉGIE DE MARQUE PERSONNELLE POUR UN PROFESSIONNEL

Ce que tu comprends et peux expliquer.

CONTENU → ATTENTION → CONFIANCE → CONVERSATION → QUALIFICATION → OFFRE → CLIENT → RÉSULTAT → ÉTUDE DE CAS → CONTENU

# NIVEAU Q — BRANDING, MARKETING ET VENTE : LES GRANDES DÉCISIONS

# 105\. QUAND UTILISER LE PERSONAL BRANDING ?

À privilégier lorsque :

- la confiance dans la personne est importante ;
- l’expertise est centrale ;
- la vente est relationnelle ;
- le fondateur représente fortement l’activité ;
- le contenu éducatif est pertinent.

# 106\. QUAND PRIVILÉGIER UNE MARQUE D’ENTREPRISE ?

Lorsque :

- plusieurs personnes portent l’offre ;
- l’entreprise doit être indépendante du fondateur ;
- l’image institutionnelle est importante ;
- le produit doit devenir une entité autonome.

# 107\. PERSONAL BRANDING OU BRANDING D’ENTREPRISE ?

Ce n’est pas nécessairement :

l’un OU l’autre.

On peut avoir :

**PERSONNE → marque personnelle**

et :

**ENTREPRISE → marque commerciale**

avec une relation cohérente entre les deux.

# 108\. ORGANIC OU PAID ?

### Organic

Avantages :

- effet cumulatif ;
- crédibilité ;
- contenu durable ;
- communauté.

Inconvénients :

- lent ;
- incertain ;
- demande de la constance.

### Paid

Avantages :

- contrôle du ciblage ;
- vitesse ;
- volume.

Inconvénients :

- coût ;
- dépendance au budget ;
- nécessité d’optimisation.

# 109\. INBOUND OU OUTBOUND ?

### Inbound

Le marché vient progressivement vers toi.

### Outbound

Tu vas directement chercher le marché.

Une entreprise peut combiner les deux.

# 110\. LARGE AUDIENCE OU NICHE ?

Une grande audience n’est pas automatiquement meilleure.

Une niche peut produire :

- meilleure pertinence ;
- meilleure conversion ;
- meilleure réputation ;
- message plus précis.

Question à poser :

**Quelle audience maximise la valeur, pas seulement la visibilité ?**

transformer l’intérêt en résultat commercial.

# NIVEAU W — CONFUSIONS À ÉLIMINER

## Branding vs Marketing

Branding = perception et identité.

Marketing = stratégie de marché et génération de demande.

## Marketing vs Sales

Marketing = attirer et créer de la demande.

Sales = convertir les opportunités.

## Audience vs Community

Audience = personnes exposées.

Community = personnes engagées dans une relation collective.

## Reach vs Impressions

Reach = personnes/comptes uniques atteints selon la définition de la plateforme.

Impressions = nombre d’affichages.

## Visibility vs Authority

Visibilité = être vu.

Autorité = être reconnu comme pertinent ou compétent.

## Engagement vs Conversion

Engagement = interaction.

Conversion = action définie comme objectif.

## Customer vs User

Customer = personne/organisation qui achète.

User = personne qui utilise.

Ils peuvent être différents.

## Lead vs Customer

Lead = opportunité potentielle.

Customer = client acquis.

## Prospect vs Lead

Les définitions varient selon les organisations.

Il faut surtout comprendre la logique :

contact potentiel → qualification → opportunité → client.

## Content vs Content Strategy

Content = actif individuel.

Content strategy = système qui détermine pourquoi, pour qui, quoi, comment et avec quelle mesure.

## Personal Branding vs Ego

Personal branding :

rendre sa valeur professionnelle identifiable.

Ego :

recherche de valorisation personnelle.

Ils ne sont pas synonymes.

## Storytelling vs Mensonge

Le storytelling organise la réalité en récit.

Il ne justifie pas l’invention de faits.

# 145\. CONCLUSION

Le branding, le marketing et le personal branding ne constituent pas trois activités isolées.

Ils forment un système.

**BRANDING**

construit la perception.

**MARKETING**

met l’offre en relation avec le marché.

**CONTENU**

attire, éduque, démontre et entretient la relation.

**PERSONAL BRANDING**

rend une personne professionnellement identifiable.

**VENTE**

transforme l’intérêt en transaction.

**RÉPUTATION**

accumule les conséquences des expériences passées.

Le modèle global devient :

**IDENTITÉ → POSITIONNEMENT → OFFRE → VISIBILITÉ → ATTENTION → CONFIANCE → CONVERSATION → QUALIFICATION → VENTE → EXPÉRIENCE → PREUVE → RÉPUTATION → RECOMMANDATION → CROISSANCE**

Et la compétence recherchée n’est pas :

« savoir faire des posts ».

Elle est :

**comprendre comment une valeur devient visible, crédible, choisie, achetée et recommandée.**

C’est cette compréhension qui permet ensuite de travailler intelligemment avec l’IA, les réseaux sociaux, les commerciaux, les designers, les développeurs, les partenaires, les clients et les financeurs.
